# SQL Retail Store Data Analysis

## 📌 Project Overview

This project focuses on analyzing retail store data using SQL to solve real-world business questions and derive meaningful insights.

The project works with relational data related to customers, products, orders, order items, and payments.

## 🛠️ Tools & Technologies

- SQL
- MySQL
- Relational Database
- Data Analysis

## 📊 SQL Concepts Used

- SELECT
- WHERE
- DISTINCT
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- Subqueries
- EXISTS / NOT EXISTS
- UNION / UNION ALL
- Filtering and Sorting

## 📂 Project Structure

- `retail_store_analysis.sql` – SQL queries used for the analysis
- - [Project Report](./SQL_Retail_Store_Data_Analysis.pdf.pdf) – Project questions, queries and outputs
